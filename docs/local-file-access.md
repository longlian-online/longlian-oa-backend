# 本地文件读取权限

本地读取 URL 使用 HMAC-SHA256 签名，绑定 key 和过期时间，默认有效期 300 秒。
业务接口必须先验证资源访问权限，再调用 ResourceService 获取读取 URL。
持有有效签名链接即可在有效期内读取该文件，支持头像、封面及组织共享资料的浏览器直接加载。
签名仅授权读取，不授权 PUT 上传，也不能用于读取其他资源。

裸 key、篡改链接和过期链接均无法读取；匿名读取入口保留用于验证签名，
并非仅凭登录状态或上传者身份决定共享资源访问权限。
资源 ID、文件内容和历史业务引用保持不变，旧的裸 key URL 需重新通过业务接口获取。

可用 `STORAGE_LOCAL_SIGNING_SECRET` 设置至少 32 字节的独立密钥，默认复用 JWT 密钥，
签名载荷有独立用途标识。`STORAGE_LOCAL_READ_URL_TTL_SECONDS` 控制有效期。
多实例应使用同一签名密钥并保持时钟同步。密钥轮换使旧链接失效；前端链接过期后重新请求业务接口。
不要将完整签名链接写入访问日志或公开分享。
